Assignment 1: Hierarchical Inheritance - Employee, Developer & Tester

Scenario: Model an organization structure where Developer and Tester inherit common fields (name, salary) and behaviour (displayDetails()) from a base Employee class.

Inheritance Concept: Hierarchical Inheritance with class Developer extends Employee and class Tester extends Employee. Subclasses add specialized fields (programmingLanguage, testingTool) while reusing base class methods.

package com.java.Assignment2;

class Employee {
    String name;
    double salary;

    void displayDetails() {
        System.out.println("Name: " + name);
        System.out.println("Salary: " + salary);
    }
}

class Developer extends Employee {
    String programmingLanguage;

    void displayDeveloper() {
        displayDetails();
        System.out.println("Programming Language: " + programmingLanguage);
    }
}

class Tester extends Employee {
    String testingTool;

    void displayTester() {
        displayDetails();
        System.out.println("Testing Tool: " + testingTool);
    }
}

public class EmployeeDetails {
    public static void main(String[] args) {
        Developer dev = new Developer();
        dev.name = "Kim Min-jun";
        dev.salary = 40000;
        dev.programmingLanguage = "Java";

        Tester test = new Tester();
        test.name = "Park Seo-yeon";
        test.salary = 35000;
        test.testingTool = "Selenium";

        dev.displayDeveloper();
        System.out.println();

        test.displayTester();
    }
}

Assignment 2: Method Inheritance - Vehicle, Car & Bike

Scenario: Define generic vehicle behaviours (start(), stop()) in a base Vehicle class, and extend them in Car and Bike subclasses.

Inheritance Concept: Subclasses Car and Bike automatically inherit methods start() and stop() from parent Vehicle without re-writing code, fulfilling fundamental DRY (Don't Repeat Yourself) OOP principles.

package com.java.Assignment2;

class Vehicle {
    void start() {
        System.out.println("Vehicle Started");
    }

    void stop() {
        System.out.println("Vehicle Stopped");
    }
}

class Car extends Vehicle {
    void displayType() {
        System.out.println("Type: Car");
    }
}

class Bike extends Vehicle {
    void displayType() {
        System.out.println("Type: Bike");
    }
}

public class VehicleDetails {
    public static void main(String[] args) {
        Car car = new Car();
        car.displayType();
        car.start();
        car.stop();

        System.out.println();

        Bike bike = new Bike();
        bike.displayType();
        bike.start();
        bike.stop();
    }
}
