Assignment 1: Find the First Non-Repeated Character

Scenario: Given an input string, identify and output the first character that appears exactly once across the entire sequence.

String Manipulation Concept: Nested character frequency inspection using charAt() and Character.toLowerCase() to find unique characters without altering case semantics.

package com.java.Assignment2;

public class FindString {
	public static void main(String[] args) {
		String Input = "swiss";

		for (int a = 0; a < Input.length(); a++) {
			char ch = Input.charAt(a);
			boolean isRepeated = false;

			for (int b = 0; b < Input.length(); b++) {
				if (a != b && Character.toLowerCase(ch) == Character.toLowerCase(Input.charAt(b))) {
					isRepeated = true;
					break;
				}
			}

			if (!isRepeated) {
				System.out.println(ch);
				break;
			}
		}
	}
}

Assignment 2: Remove Duplicate Characters Maintaining Order

Scenario: Filter an input string by removing all duplicate characters while strictly preserving the first appearance order of every character.

String Manipulation Concept: Dynamic string concatenation with accumulator buffer checking (Output.charAt(b)) before appending new characters.

package com.java.Assignment2;

public class DuplicateCharacter {

    public static void main(String[] args) {

        String Input = "Programming";
        String Output = "";

        for (int a = 0; a < Input.length(); a++) {

            boolean found = false;

            for (int b = 0; b < Output.length(); b++) {
                if (Input.charAt(a) == Output.charAt(b)) {
                    found = true;
                    break;
                }
            }

            if (!found) {
                Output += Input.charAt(a);
            }
        }

        System.out.println(Output);
    }
}

Assignment 3: Reverse Each Word in a Sentence

Scenario: Take an entire sentence and reverse the letters of each individual word without shifting word positions.

String Manipulation Concept: Delimiter tokenization with split(" ") and reverse decrement loop (b = words[a].length() - 1; b >= 0; b--) for in-place token inversion.

package com.java.Assignment2;

public class ReverseWords {

    public static void main(String[] args) {

        String input = "Java is easy";
        String[] words = input.split(" ");

        for (int a = 0; a < words.length; a++) {

            for (int b = words[a].length() - 1; b >= 0; b--) {
                System.out.print(words[a].charAt(b));
            }

            if (a < words.length - 1) {
                System.out.print(" ");
            }
        }
        System.out.println();
    }
}
