Assignment 4: Constructor Overloading

Scenario: An online shopping application allows products to be created with different levels of information.

Concept: Demonstrates constructor overloading with 3 distinct constructors: default no-arg, 2-arg (id, name), and 3-arg (id, name, price).

Product.java package com.javaExercise Constructor Overloading
Product.java
Download .java 
package com.javaExercise;

public class Product {

    int productId;
    String productName;
    double price;

    Product() {
        productId = 0;
        productName = "Unknown";
        price = 0.0;
    }

    Product(int productId, String productName) {
        this.productId = productId;
        this.productName = productName;
        price = 0.0;
    }

    Product(int productId, String productName, double price) {
        this.productId = productId;
        this.productName = productName;
        this.price = price;
    }

    void displayDetails() {
        System.out.println("Product ID: " + productId);
        System.out.println("Product Name: " + productName);
        System.out.println("Price: " + price);
        System.out.println("                  ");
    }

    public static void main(String[] args) {

        Product p1 = new Product();
        Product p2 = new Product(101, "Laptop");
        Product p3 = new Product(102, "Headphones", 2500);

        p1.displayDetails();
        p2.displayDetails();
        p3.displayDetails();
    }
}

Assignment 5: Copy Constructor

Scenario: A school needs to create a new student record by copying the details of an existing student.

Concept: Demonstrates a Copy Constructor that accepts another StudentRecords object and copies its values, proving that modifying the copied object's marks does not alter the original student's marks.

StudentRecords.java package com.javaExercise Copy Constructor
StudentRecords.java
Download .java 
package com.javaExercise;

public class StudentRecords {

    int rollNumber;
    String studentName;
    double marks;

    StudentRecords(int rollNumber, String studentName, double marks) {
        this.rollNumber = rollNumber;
        this.studentName = studentName;
        this.marks = marks;
    }

    StudentRecords(StudentRecords student) {
        this.rollNumber = student.rollNumber;
        this.studentName = student.studentName;
        this.marks = student.marks;
    }

    void displayDetails() {
        System.out.println("Roll Number: " + rollNumber);
        System.out.println("Student Name: " + studentName);
        System.out.println("Marks: " + marks);
        System.out.println("                  ");
    }

    public static void main(String[] args) {

        StudentRecords s1 = new StudentRecords(101, "Arun", 85);
        StudentRecords s2 = new StudentRecords(s1);

        s2.marks = 95;

        System.out.println("Original Student:");
        s1.displayDetails();

        System.out.println("Copied Student:");
        s2.displayDetails();
    }
}
Console Output (Verified Output)
